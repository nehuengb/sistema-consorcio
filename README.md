# 🏢 Sistema de Gestión de Consorcio

Aplicación web para la administración de edificios, control de accesos/usuarios y gestión de reclamos.

## 🚀 Tecnologías
* **Backend:** PHP
* **Base de Datos:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript
* **Entorno de pruebas:** XAMPP (Apache / MySQL)

## ✨ Funcionalidades clave
* Control de roles (Administrador, Propietario, Inquilino)
* Módulo de altas y seguimiento de reclamos
* Agenda y avisos para la comunidad
